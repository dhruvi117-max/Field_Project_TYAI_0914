# Staged-shelf evaluation photos

Keep the original photos in this folder. They are ignored by Git because they
are your real project evidence and may be private.

For each photograph:

1. Count the real facings and products before using the application.
2. Add that ground truth in `evaluation_template.csv`.
3. Upload the same photo, complete Human review, and record the confirmed result.
4. Include normal, angled and low-light cases. Also include a photo with a
   deliberately low-facing product if you need to prove the restock reminder.

This converts your own photos into defensible evaluation evidence. Do not
report count error or mismatch precision/recall until the ground truth columns
have been completed.

## Suggested starting planogram

`suggested_reference_planogram.csv` is a practical starting reference based on
the full staged shelf photograph. In the dashboard, add each listed product
name and optional OCR words, then add the row, expected facings and minimum.
Save it for the same store and shelf identifiers used during the audit. Adjust
it if a different photograph is your intended fully-stocked reference.
